\# AI Business Intelligence System



\## Project Overview



AI Business Intelligence is a web-based application designed to manage business transactions and generate useful business insights. It helps organize sales, purchases, expenses, customers, and products.



\## Features



\* Sales and purchase management

\* Customer and product management

\* Expense tracking

\* Transaction reporting and analytics

\* AI-assisted business insights

\* Document upload and processing



\## Technologies Used



\* Python

\* Flask

\* PHP

\* MySQL

\* HTML

\* CSS



\## Database



The project uses MySQL to store business data. Import `ai\_business\_intelligence.sql` into your local MySQL database before running the application.



\## Local Setup



1\. Clone or download this repository.

2\. Set up PHP and MySQL using a local server such as WAMP.

3\. Import `ai\_business\_intelligence.sql` into MySQL.

4\. Configure the database connection in `db.php`.

5\. Create your local `config.local.php` using the template in `config.example.php`.

6\. Run the project on your local server.
